# Machine Learning: Linear, Polynomial and Regularized Regression

## 📌 Overview

This repository contains a Jupyter Notebook demonstrating fundamental regression techniques in machine learning using Python and Scikit-Learn.

The notebook covers:

* Linear Regression
* Normal Equation
* Gradient Descent
* Stochastic Gradient Descent (SGD)
* Polynomial Regression
* Learning Curves
* Ridge Regression (L2 Regularization)
* Model Visualization

The examples use synthetically generated datasets to illustrate how different regression algorithms learn patterns from data.

## 📈 Topics Covered

### 1. Linear Regression

* Generating synthetic linear data
* Visualizing training samples
* Solving regression using the Normal Equation
* Predicting new values
* Comparing manual implementation with Scikit-Learn

### 2. Gradient Descent

* Implementing Batch Gradient Descent from scratch
* Updating model parameters iteratively
* Understanding convergence behavior

### 3. Stochastic Gradient Descent (SGD)

* Training regression models using `SGDRegressor`
* Comparing SGD with analytical solutions

### 4. Polynomial Regression

* Creating non-linear datasets
* Feature transformation using `PolynomialFeatures`
* Fitting polynomial models
* Visualizing polynomial decision curves

### 5. Learning Curves

* Evaluating model performance
* Detecting underfitting and overfitting
* Training vs validation error analysis

### 6. Regularized Regression

Implementation of:

* Ridge Regression (L2 Regularization)

Demonstrates how regularization reduces overfitting and improves generalization.
